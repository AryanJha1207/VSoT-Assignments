Question 2

Array_Trapping Rain Water

Given an array `height` of non-negative integers representing the height of blocks, where the width of each block is `1`, determine how many units of water can be trapped after raining.

## Input Format

- The first line contains an integer `N` — the number of blocks.
- The second line contains `N` space-separated integers representing the height of each block.

## Output Format

Print a single integer representing the total amount of trapped rainwater.

Example 1:

Input:

```
12
0 1 0 2 1 0 1 3 2 1 2 1
```

Output:

```
6
```

Constraints:

```
1 <= N <= 2 × 10^4
0 <= height[i] <= 10^5
```
