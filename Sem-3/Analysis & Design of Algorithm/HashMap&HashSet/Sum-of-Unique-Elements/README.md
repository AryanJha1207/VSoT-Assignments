Sum of Unique Elements

Given an integer array `nums`, return the sum of all the unique elements. A unique element is an element that appears exactly once in the array.

**Input Format**

The only line contains space-separated integers representing `nums`

**Output Format**

Print the sum of all unique elements

Example 1:

Input:

```
1 2 3 2
```

Output:

```
4
```

Constraints:

```
1 ≤ nums.length ≤ 100
1 ≤ nums[i] ≤ 100
```
