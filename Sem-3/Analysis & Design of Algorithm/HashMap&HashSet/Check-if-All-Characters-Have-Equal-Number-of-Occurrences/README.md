Question 3

Map_Check if All Characters Have Equal Number of Occurrences

Given a string `s`, return `True` if all characters in `s` appear the same number of times, otherwise return `False`.

**Input Format**

The only line contains a string `s`

**Output Format**

Print `True` or `False`

Example 1:

Input:

```
abacbc
```

Output:

```
True
```

Example 2:

Input:

```
z
```

Output:

```
True
```

Constraints:

```
1 ≤ s.length ≤ 1000
s contains only lowercase English letters
```
