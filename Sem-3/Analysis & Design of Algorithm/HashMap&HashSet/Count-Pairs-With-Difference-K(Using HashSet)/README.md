Map_Count_Pairs_With_Difference_K

Given an array and an integer K, count the number of unique pairs having difference exactly K.

### Input Format:

First line contains N and K.

Second line contains N integers.

### Output Format:

Print count of pairs.

###

Example 1:

Input:

```
5 2
1 3 5 7 9
```

Output:

```
4
```

Constraints:

```
1<=N<=10^5
1<=Arr[i]<=10^5
```
