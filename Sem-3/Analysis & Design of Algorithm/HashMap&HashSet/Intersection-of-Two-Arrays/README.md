Map_Intersection_of_Two_Arrays

Given two arrays, find all distinct common elements present in both arrays.

### Input Format:

First line contains two integers N and M denoting the size of the two arrays.

Second line contains N integers.

Third line contains M integers.

### Output Format:

Print all distinct common elements in sorted order.

Example 1:

Input:

```
4 4
10 20 30 40
20 50 60 40
```

Output:

```
20 40
```

Constraints:

```
1 ≤ N ≤ 10^5
1 ≤ Arr[i] ≤ 10^5
```
