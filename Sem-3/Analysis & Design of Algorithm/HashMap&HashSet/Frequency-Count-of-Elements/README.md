Question 6

Map_Frequency Count of Elements

Given an array of integers `nums`, return a dictionary containing the frequency of each element.

The result should be sorted in **ascending order of keys**.

Example 1:

Input:

```
1 2 2 3 1 1
```

Output:

```
{1: 3, 2: 2, 3: 1}
```

Constraints:

```
1≤n≤1000

−10^4≤nums[i]≤10^4
```
