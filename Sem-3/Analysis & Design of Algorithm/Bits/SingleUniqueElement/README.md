BIT_SingleUniqueElement

In a magical kingdom, every number in an array appears exactly **twice**, except for one special number which appears **only once**.

Your task is to find and return the **single unique element** from the array.

You must solve the problem using **bitwise operations**.

Example 1:

Input:

```
5
1 2 2 1 3
```

Output:

```
3
```

Constraints:

```
1 ≤ N ≤ 10^5
-10^9 ≤ A[i] ≤ 10^9
Exactly one element appears once, all others appear twice
```
