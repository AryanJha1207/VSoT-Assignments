Question 2

Bit_CountSetBits

Given a positive integer `N`, count the number of **set bits (**`1`**s)** in its binary representation.

Example 1:

Input:

```
10
```

Output:

```
2
```

Constraints:

```
1 <= N <= 10^9
```
