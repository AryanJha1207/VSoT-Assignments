Question 1

Array_RunningSumOfArray

Given an integer array `nums`, return its **running sum**.

The running sum of an array is defined as:

```
runningSum[i] = nums[0] + nums[1] + ... + nums[i]
```

## Input Format

- The first line contains an integer `N` — the size of the array.
- The second line contains `N` space-separated integers.

## Output Format

Print the running sum array.

Example 1:

Input:

```
4
1 2 3 4
```

Output:

```
1 3 6 10
```

Constraints:

```
1 <= N <= 1000
-10^6 <= nums[i] <= 10^6
```
