# 🧠 Python Vedamian’s Self-Check Program

## 📘 Problem Description

A **Vedamian** is learning **conditional statements** for the first time.

To practice, they decide to build a small **self-evaluation program** before exams.

### 💡 Idea:

* Enter your marks
* The program evaluates your performance and tells whether you are:

  * ✅ **CONFIDENT**
  * 📚 **NEEDS PRACTICE**
  * 🔁 **REPEAT COURSE**

The logic must be implemented using **only `if` and `else` statements** (no `elif` allowed).

---

## 📥 Input

You are given a single integer:

* `M` → Marks obtained (out of 100)

---

## 📏 Self-Evaluation Rules

* If `M ≥ 70` → **CONFIDENT**
* Else if `M ≥ 40` → **NEEDS PRACTICE**
* Else → **REPEAT COURSE**

---

## 📤 Output

Print the appropriate self-evaluation result.

---

## 🧪 Sample Test Case

### Input

```id="p9k2lx"
78
```

### Output

```id="z7m4qa"
CONFIDENT
```
