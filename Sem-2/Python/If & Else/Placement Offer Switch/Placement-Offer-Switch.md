# 🏫 Python Placement Offer Switch

## 📘 Problem Description

At **Vedam School of Technology**, final placement results are determined through an automated system.

Each **B.Tech student** submits their final **CGPA**, and based on this value, the system assigns **only one outcome**:

* ✅ Direct Placement Offer
* 📚 Training Required
* ❌ Not Eligible

The system evaluates conditions step-by-step, similar to a chain of **if–else statements**.

---

## 📥 Input

You are given a single integer:

* `C` → CGPA multiplied by 10

---

## 📏 Placement Rules

* If `C ≥ 80` → **PLACED**
* Else if `C ≥ 60` → **TRAINING**
* Else → **NOT ELIGIBLE**

---

## 📤 Output

Print the placement result based on the given CGPA.

---

## 🧪 Sample Test Case

### Input

```
85
```

### Output

```
PLACED
```
