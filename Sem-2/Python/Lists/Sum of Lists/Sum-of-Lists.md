# 📊 Python List: Sum of List

## 📘 Problem Description

You are given an array of size `N`.
Your task is to compute and print the **sum of all elements** in the array.

---

## 📏 Constraints

* `1 ≤ N ≤ 100`

---

## 📥 Input

* First line: Integer `N` → size of the array
* Next `N` lines: Integers representing the elements of the array

---

## 📤 Output

* Print the **sum of all elements** in the array

---

## 🧪 Sample Test Case

### Input

```id="k3x9mp"
5
10
20
30
40
50
```

### Output

```id="z7q2vn"
150
```

---

## 💡 Explanation

Array elements:

* 10, 20, 30, 40, 50

Sum:
[
10 + 20 + 30 + 40 + 50 = 150
]
