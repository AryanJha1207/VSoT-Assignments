# 🔢 Python List: Find Second Largest Element

## 📘 Problem Description

Create a function `find_second_largest` that takes an array of integers as input and returns the **second largest element** in the array.

* If the second largest element does **not exist**, print `-1`.

---

## 📏 Constraints

* `2 ≤ N ≤ 1000`
* `-10^5 ≤ arr[i] ≤ 10^5`

---

## 📥 Input Format

* First line: Integer `N` → size of the array
* Second line: `N` space-separated integers → elements of the array

---

## 📤 Output Format

* Print a single integer → **second largest element**
* If not present, print `-1`

---

## 🧪 Sample Test Case

### Input

```id="k9x2mp"
7
2 90 8 12 22 39 2
```

### Output

```id="z7q4vn"
39
```

---

## 💡 Explanation

Array:

* 2, 90, 8, 12, 22, 39, 2

* Largest element → `90`

* Second largest element → `39`
