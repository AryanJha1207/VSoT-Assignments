# 🐍 **Python Variable Addition**

## 📊 **Success Rate:** 69.94%

### 🎯 **Problem Statement**
Take two numbers as input from the user, store them in variables, and print their sum.

---

### ⚠️ **Problem Constraint**
Numbers are integers.

---

### ⌨️ **Input Format**
Two integers:
```
a
b
```

---

### 📤 **Output Format**
Print the sum of the two numbers.

---

### 🧪 **Sample Test Cases**
| Input | Expected Output |
| :--- | :--- |
| `10`<br>`20` | `30` |

---

### 💡 **Solution**
```python
a = int(input())
b = int(input())
print(a + b)
```
