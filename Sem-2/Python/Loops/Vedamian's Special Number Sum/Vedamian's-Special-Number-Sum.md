# 🔢 Python Vedamian’s Special Number Sum

## 📘 Problem Description

A **Vedamian** is preparing for coding interviews and wants to strengthen their understanding of **loops and number logic**.

They create a challenge:

From `1` to `N`, add only those numbers that satisfy specific conditions.

---

## 🎯 Task

Given an integer `N`, calculate the **sum of all numbers from 1 to N** that satisfy **both** of the following conditions:

* The number is **divisible by 3**
* The number does **NOT end with digit 9**

---

## 📥 Input

* A single integer `N`

---

## 📤 Output

* Print the **required sum**

---

## 🧪 Sample Test Case

### Input

```id="k9v2mz"
20
```

### Output

```id="x4q7pl"
54
```

---

## 💡 Explanation

Numbers from `1` to `20` divisible by `3`:

* 3, 6, 9, 12, 15, 18

Exclude numbers ending with `9`:

* ❌ 9

Remaining numbers:

* 3, 6, 12, 15, 18

Sum:
[
3 + 6 + 12 + 15 + 18 = 54
]
