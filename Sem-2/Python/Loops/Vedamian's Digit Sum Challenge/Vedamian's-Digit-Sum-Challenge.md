# 🔢 Python Vedamian’s Digit Sum Challenge

## 📘 Problem Description

A **Vedamian** is practicing **loops in Python**.

To better understand how a `while` loop works, they pick a number and decide to calculate the **sum of its digits**.

### 💡 Example:

If the number is `12345`, the program should compute:

[
1 + 2 + 3 + 4 + 5 = 15
]

Your task is to help the Vedamian implement this using a **while loop**.

---

## 📥 Input

* A single integer `n`

---

## 📤 Output

* Print the **sum of the digits** of the number

---

## 🧪 Sample Test Case

### Input

```id="m8z4qn"
12345
```

### Output

```id="x2v7kp"
15
```

---

## 💡 Explanation

Digits of `12345` are:

* 1, 2, 3, 4, 5

Their sum is:
[
1 + 2 + 3 + 4 + 5 = 15
]
