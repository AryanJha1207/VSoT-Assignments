# 🔢 Python Loop: Sum of First N Numbers

## 📘 Problem Description

You are given an integer `N`.
Your task is to compute the **sum of the first N natural numbers**.

### 🧮 Mathematical Representation:

[
1 + 2 + 3 + \dots + N
]

---

## 📥 Input Format

* A single integer `N`

---

## 📤 Output Format

* Output a single integer representing the **sum of the first N natural numbers**

---

## 🧪 Sample Test Case

### Input

```id="k3m9vd"
5
```

### Output

```id="u8x2pq"
15
```

---

## 💡 Explanation

For `N = 5`:

[
1 + 2 + 3 + 4 + 5 = 15
]
