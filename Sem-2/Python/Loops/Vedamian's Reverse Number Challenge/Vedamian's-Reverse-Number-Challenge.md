# 🔄 Python Vedamian’s Reverse Number Challenge

## 📘 Problem Description

A **Vedamian** is practicing **number manipulation using loops**.

To strengthen their understanding, they decide to write a program that **reverses a given number**.

### 💡 Example:

If the number is `1234`, the reversed number should be:

[
4321
]

---

## 📥 Input

* A single integer `n`

---

## 📤 Output

* Print the **reversed number**

---

## 🧪 Sample Test Case

### Input

```id="r7k2pz"
12345
```

### Output

```id="y4m8qx"
54321
```

---

## 💡 Explanation

Digits of `12345`:

* 1, 2, 3, 4, 5

Reversing them gives:
[
54321
]
