# ⬛ Python Pattern: Solid Square Pattern

## 📘 Problem Description

Print a **solid square pattern** of size `n × n` using asterisks (`*`).

---

## ✨ Pattern Rules

* The pattern consists of `n` rows
* Each row contains exactly `n` asterisks (`*`)
* No spaces or gaps between the stars

---

## 📥 Input Format

* A single integer `n`
* Constraint: `1 ≤ n ≤ 100`

---

## 📤 Output Format

* Print the **solid square pattern**

---

## 🧪 Sample Test Case

### Input

```id="k9x2mp"
4
```

### Output

```id="z7q4vn"
****
****
****
****
```

---

## 💡 Explanation

For `n = 4`:

* Total rows = 4
* Each row contains 4 stars

This forms a **4 × 4 solid square**.
